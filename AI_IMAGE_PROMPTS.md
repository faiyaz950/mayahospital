# Maya Hospital — AI Image Prompts

Har prompt ko ChatGPT (image), Google Gemini, Midjourney ya Ideogram me paste karein.
Bani hui image ko **bataye gaye exact file name** se `assets/img/` folder me save karein.
Website apne aap photo dikhayegi; file na ho to illustration dikhta rahega.

**Sabhi images ke liye:**
- Format: `.jpg`, width kam se kam 1600px, size 500 KB se kam rakhein (compress: squoosh.app).
- Image me koi text, logo, watermark ya nakli signboard na ho.
- Theme colours: dark green (#0a3a2b) aur heart red (#d42029) halke accents me.

Ye style line har prompt ke end me jodein:

> Photorealistic, professional architectural/medical photography, natural soft daylight, clean modern Indian private hospital, dark green and subtle red accents, shallow depth of field, high detail, no text, no logos, no watermark.
